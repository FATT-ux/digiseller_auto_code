# 🤖 Автовыдача кодов подтверждения для Plati.Market и GGSel (Digiseller API)

Python-бот для автоматической выдачи кодов верификации (Steam Guard, Microsoft/Xbox, Epic Games и др.) покупателям в чатах заказов на площадках **Plati.Market** и **GGSel** через официальный **Digiseller API**.

---

## ⚙️ Как работает скрипт

1. Каждые 7 секунд опрашивает API Digiseller на наличие новых непрочитанных сообщений в чатах с покупателями.
2. При получении команды **`!код`** проверяет статус оплаты заказа.
3. Определяет купленный товар и подключается по протоколу **IMAP** к привязанному почтовому ящику.
4. Находит последнее письмо от нужного сервиса, извлекает код подтверждения и отправляет его в ответном сообщении покупателю.
5. Отправляет уведомление продавцу в **Telegram-бота** с номером заказа, названием товара и выданным кодом.

## 🛠 Подготовка данных перед запуском

### 1. Получение ключей Digiseller
1. Зайдите в личный кабинет продавца **[Digiseller](https://digiseller.com)**.
2. Скопируйте ваш числовой **ID продавца** (`SELLER_ID`) из шапки кабинета.
3. Перейдите в раздел **Настройки → API ключи** (`https://digiseller.cominside/api_keys.asp`).
4. Создайте новый ключ и отметьте для него **только 3 права доступа**:
   * **Операции** → `Детали счета`
   * **Переписка с покупателями** → `Просматривать`
   * **Переписка с покупателями** → `Отправить`
5. Скопируйте сгенерированный ключ (`API_KEY`).

### 2. Настройка почты (IMAP)
Обычный пароль от почты не подойдет — необходимо создать **пароль приложения**:
* **Gmail (`://gmail.com`):** Включите двухэтапную аутентификацию в Google Аккаунте → раздел *Безопасность* → *Пароли приложений* → создайте пароль для приложения *Почта*. В настройках самой почты Gmail включите доступ по **IMAP**.
* **Яндекс Почта (`imap.yandex.ru`):** *Яндекс ID* → *Безопасность* → *Пароли приложений* → *Почта*. В настройках ящика разрешите доступ по протоколу IMAP.
* **Mail.ru (`imap.mail.ru`):** *Настройки безопасности* → *Пароли для внешних приложений*.

### 3. Создание Telegram-бота (опционально)
1. Напишите официальному боту **`@BotFather`** команду `/newbot`, задайте имя и получите токен (`TG_BOT_TOKEN`).
2. Откройте созданного бота и обязательно нажмите кнопку **Старт** (`/start`).
3. Узнайте свой числовой ID (`TG_CHAT_ID`) через бота **`@userinfobot`**.

## 🚀 Установка и запуск

### 1. Клонирование репозитория и установка библиотек
Убедитесь, что на устройстве установлен **Python 3.10+**.

```bash
git clone https://github.com
cd ВАШ_РЕПОЗИТОРИЙ
pip install -r requirements.txt
```

### 2. Настройка конфигурации
1. Откройте **`config.py`** и впишите свои данные (`SELLER_ID`, `API_KEY`, данные почты и Telegram).

#### Шпаргалка по настройке `sender` и `code_regex` под разные сервисы:
* **Steam:** `"sender": "noreply@steampowered.com"`, `"code_regex": r"\b([A-Z0-9]{5})\b"`
* **Microsoft / Xbox:** `"sender": "://microsoft.com"`, `"code_regex": r"\b(\d{6,7})\b"`
* **Epic Games:** `"sender": "epicgames.com"`, `"code_regex": r"\b(\d{6})\b"`
* **PlayStation (PSN):** `"sender": "sonyentertainmentnetwork.com"`, `"code_regex": r"\b(\d{6})\b"`

### 3. Запуск бота
```bash
python main.py
```
При успешном запуске в консоли появится сообщение:
```text
Бот автовыдачи кодов запущен. Ожидание сообщений...
```

## 💡 Рекомендации по эксплуатации

* **Инструкция для покупателей:** В описание товара и в автовыдачу на Plati.Market / GGSel добавьте текст: *«Для получения кода подтверждения с почты напишите в переписку по заказу команду `!код`»*.
* **Работа без Telegram / без VPN:** Если скрипт запущен в регионе с ограничением доступа к `api.telegram.org` и вы не используете VPN, просто закомментируйте строку вызова `send_tg_notification(...)` в файле `main.py` (поставив `#` в начале строки). Выдача кодов покупателям продолжится в штатном режиме.
* **Безопасность:** Никогда не загружайте заполненный файл `config.py` в публичные репозитории — он уже добавлен в `.gitignore`.
